Flip 7

TypeScript · PixiJS · Cloudflare Workers

A multiplayer web version of the Flip 7 card game, built in TypeScript with a PixiJS client and a server-authoritative backend on Cloudflare Workers. Each room is its own Durable Object that owns the deck and the full rules engine, so clients only send intents (hit, stay, flip, give a card) and never see the draw order. State is saved after every action and idle rooms hibernate through the WebSocket Hibernation API, so a game survives refreshes and lost connections without using any server time while nobody is playing. Turn timers and a silent removal countdown for players who drop out run on server alarms, which keeps the table moving. The rules are covered by unit tests and 400 fuzzed full games that check no card is ever lost or duplicated.

Hold'em

JavaScript · PixiJS · Cloudflare Workers

Online Texas Hold'em for up to 10 players, with a PixiJS client and a server-authoritative backend on Cloudflare Workers. Each table is a Durable Object that runs the full rules engine (raises, side pots, all-in runouts, split pots) and sends each player a view with only their own hole cards. The host sets starting chips, the starting blinds and the level where the blinds stop doubling. Turn timers run on server alarms: a player who disconnects is checked or folded automatically, and is removed if they're still gone when they have to act in the next hand. The rules are covered by unit tests and 500 random full games that check no chips are ever created or lost.

Blackjack

JavaScript · PixiJS · Cloudflare Workers

Online multiplayer blackjack for up to 7 players against the dealer, with a PixiJS client and a server-authoritative backend on Cloudflare Workers. Each table is a Durable Object that runs the full rules engine: a 6-deck shoe with a cut card, a dealer who peeks for blackjack and stands on all 17s, 3:2 naturals, doubling, and splitting up to four hands, with one card each on split aces. Players join by invite link, and anyone joining a full table watches until a seat opens. Each hand has a turn timer that stands automatically when it runs out. A player who disconnects keeps their seat for the rest of the round and is removed if they haven't come back by the next one. The host can fill empty seats with bots that play basic strategy. The rules are covered by unit tests and 500 random full rounds at a table of seven bots.
