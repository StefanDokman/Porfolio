Golf

Unity Mobile

Match 3

Unity Mobile

A mobile match-3 puzzle game featuring swap-based matching, chain-reaction cascades and smooth timed board animations. Levels are semi-procedural: each level's special blocks are hand-placed and stay the same on every play, while the standard pieces are generated fresh each time, so levels keep their designed challenge but never play out identically. Includes configurable levels and gameplay settings.

Runner

Unity Mobile

A mobile level-based runner with an unlimited number of levels. Each level is a finite run with a clear finish line, semi-randomly generated from designed segments, so every new level feels fresh while staying fair. Features heavy ad integration, with rewarded ads for revives and bonuses, interstitials between runs and banner placements, all built into the gameplay loop without breaking its flow.
