First Person Shooter

Unity

A first-person shooter built on a custom kinematic movement controller instead of Rigidbody physics, giving frame-consistent acceleration and air control. Weapons and enemies are fully data-driven through ScriptableObjects: fire mode (full-auto or semi-auto), fire rate and a procedural recoil curve are defined per weapon asset, and enemy stats and collision behaviour per enemy asset, so new variants are added without touching code.

Match 3

Unity

A match-3 game where the board's logical state is kept separate from its presentation. Each move resolves as a sequence of phases (swap, match detection, clear, gravity, refill, cascade check), and a timer-driven sequencer gates input until the animations finish, so the visuals can't drift out of sync with the board. Cascades are handled by re-running match detection after every refill until the board is stable. A from-scratch personal rebuild of a game I developed at Code Havoc, made so the code can be shown outside the NDA.

Endless Runner

Unity

An endless runner with deterministic, position-based gameplay and no physics engine. It features a custom toon shader with screen-wide vertex distortion that curves the entire world, so all gameplay stays in straight lines while the curvature is purely visual. The same shader handles stylised lighting and outlines in a single pass to keep GPU overhead low. Track segments and obstacles are fully object-pooled to avoid runtime allocations and instantiation spikes, spawned by a sliding-window algorithm, with character states driven by Unity's Animator.

Platformer 3D

Unity

A 3D platformer with a hybrid approach to physics: custom movement and jump integration for tight, tunable control, while Unity's collision detection resolves contacts with terrain and hazards. Moving platforms carry the player by passing on their velocity. Static level geometry uses baked lightmaps, with light probes lighting the player and moving elements, which keeps real-time lighting cost low.

Twin Stick Shooter

Unity

A 2D tank shooter with tank-style controls (rotate in place, drive forward or back) and a time-slow ability driven by a custom time system built on unscaled delta time, instead of changing the global Time.timeScale. Enemies spawn on a ring just outside the camera's bounds, computed from the viewport, so they never appear on screen. Both enemies and projectiles are object-pooled to avoid runtime allocations.

Brick Breaker

Unity

A brick breaker that skips the physics engine and handles ball movement, collision and reflection with my own vector and trigonometry math. The ball's bounce angle off the paddle depends on where it hits, which gives the player aim control. Owning the collision step makes the game's behaviour deterministic and fully tunable. A from-scratch personal rebuild of a game I developed at Code Havoc, made so the code can be shown outside the NDA.

Texture Erosion Shader

HLSL

A dissolve/erosion shader written in HLSL for dissolving cards and VFX. A noise mask combined with a UV-space direction bias decides the order in which pixels erode, a single reveal parameter drives the effect from 0 to 1 so it can be animated from code or a Timeline, and a feather parameter controls the width of the two-colour burn edge. It's one texture sample and a few ALU ops, so it's cheap enough to run on many objects at once.
